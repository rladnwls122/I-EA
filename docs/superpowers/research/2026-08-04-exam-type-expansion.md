# 전 시험 확장 조사 — 시험유형별 문항 형식·분류 요건

- 티켓: [#36](https://github.com/rladnwls122/I-EA/issues/36) (map [#33](https://github.com/rladnwls122/I-EA/issues/33))
- 전제: 분류 **구조**는 map [#24](https://github.com/rladnwls122/I-EA/issues/24)에서 이미 확정 — 별도 `SubjectDetail` 테이블(4단계, `Question.subjectDetailId` nullable FK) + Tag 카테고리 `'출제유형'`(QuestionTag로 선택 부착). 이 문서는 구조를 재설계하지 않고, **각 시험이 그 구조에 채워 넣을 값**과 **각 시험의 문항 형식**, 그리고 **현행 생성 파이프라인이 그 형식을 흉내내지 못하는 지점**만 다룬다.
- 범위: 수능(전 영역), 내신, 공무원(9급 중심), NCS 직업기초(요약만 — #24에서 완료), 토익 RC. **듣기(오디오 기반) 콘텐츠는 전부 범위 밖.**

## 요약

1. 시험별 객관식 관행이 갈린다 — **수능·내신은 5지선다, 공무원·NCS(다수 기관)·토익은 4지선다** — 그런데 현행 생성 파이프라인은 선지 개수를 지정할 수단이 없다(재생성만 2~8개 지정 가능). 선지 개수 파라미터 추가가 전 시험 공통의 최소 작업.
2. `GeminiLlmService.buildSystemPrompt()`의 "모든 텍스트는 한국어" 규칙 때문에 **영어 계열(수능/내신/공무원 영어, 토익 RC)은 현재 구조적으로 생성 불가**. 언어 파라미터가 필요하다.
3. 지문은 생성 배치당 1개(`includePassage` boolean)라 **토익 Part 7 이중·삼중지문, 수능 국어 (가)(나) 주제통합 같은 복수 지문 세트를 표현할 수 없다**(단일 지문 안에서 텍스트로 우회는 가능).
4. SubjectDetail 4단계 값은 수능·내신은 **교육과정 단원**(두 시험이 값을 공유 가능), 공무원은 **과목별 단원/시대**, NCS는 **34개 하위요소**(#30 완료), 토익 RC는 **파트별 문법·독해 포인트**로 채우면 된다. 반면 '출제유형' Tag 값은 시험마다 완전히 다르다(아래 시험별 표). 특기사항: **수능·공무원 영어는 교육과정식 '단원'이 없어 level-4보다 '출제유형' 축이 주 분류가 된다** — NCS(하위요소가 주 축)와 반대 패턴.
5. 난이도(효과 대비 노력) 순위: 공무원 9급 한국어 과목·내신 객관식·수능 국어/탐구/한국사가 거의 공짜(형식 지시 몇 줄 + 선지 개수), NCS는 분류 완료로 모듈형은 무료·PSAT형은 소규모, 내신 서술형은 중간(채점기준표·부분점수 부재), 영어 계열·토익 RC가 실 작업(한국어 강제 해제 + 다중지문), 수학 수식은 [#35](https://github.com/rladnwls122/I-EA/issues/35)가 별도 담당.

## 1. 코드베이스 현황 (그라운딩)

### 시딩된 시험·분류 — `prisma/seed.ts` `EXAM_MAP`(L376–445)

| examType | examCategory → 소분류(발췌) |

| 내신 | 국어/수학/영어(독해/어법/**듣기**)/통합사회/통합과학 |
| 공무원 9급 | 국어(문법/독해/문학/어휘), 영어(독해/어휘/문법/생활영어), 한국사, 행정법, 행정학 |
| 공무원 7급 | 헌법, 경제학, 행정법, 국어, 영어, 한국사 |
| 공기업 | NCS직업기초(능력 7개 — 공식 10개 중 3개 누락, #26에서 10개로 확장 결정), 전공 |
| 한능검 | 한국사(시대 7구분) |
| 토익 | **LC(Part1~4)**, RC(Part5\_문법/Part6\_빈칸/Part7\_독해) |

굵은 항목(수능·내신 영어 '듣기', 토익 LC)은 오디오 기반이라 이번 확장의 범위 밖 — AI 생성 대상에서 제외 플래그가 필요하다(§4-7).

`TAG_CATS`의 기존 `유형` 카테고리(L466–483)에 이미 킬러/빈칸/순서/문장삽입/자료해석/어법/어휘 등 출제유형성 값이 들어 있다. #24가 신설하기로 한 `'출제유형'` 카테고리와 의미가 겹치므로, 구현 시 기존 `유형` 태그와의 관계(병존 or 이관)를 정리해야 한다 — 구조 결정은 #24 소관이므로 여기서는 지적만 한다.

### 생성 파이프라인 — `src/modules/ai-generation/`

- 프롬프트에는 `시험/대분류/소분류` **라벨 3줄**만 주입된다(`gemini-llm.service.ts` `buildUserPrompt()` L632–656). 시험별 형식 지시(선지 개수, 발문 스타일, 지문 관행)는 전무 — `examType` 누락 시 "수능 스타일로 치우친다"는 주석이 `llm.types.ts` L81에 명시돼 있다. #28 결정대로 SubjectDetail 라벨도 같은 방식으로 프롬프트에 실리면 된다.
- **선지 개수**: 생성 시 지정 불가(`CreateGenerationDto`에 필드 없음, 검증은 "2개 이상"뿐 — `parseGenerationResult()` L517). 선지 재생성만 `choiceCount` 2~8 지정 가능(`LlmRegenerateChoicesContext`).
- **정답 개수**: 생성·재생성 모두 `isCorrect === true` 정확히 1개를 강제(L523–528, L592–597). 복수정답 문항은 검증에서 튕긴다.
- **지문**: `includePassage` boolean 하나 — 생성 배치당 passage 최대 1개, 전 문항이 그 하나에 연결된다(`ai-generation.processor.ts` L69–103).
- **언어**: 시스템 프롬프트가 "모든 텍스트는 한국어"를 강제(`buildSystemPrompt()` L559, `buildChoicesSystemPrompt()` L614).
- **수식**: LaTeX/KaTeX 금지, 순수 텍스트만(L613) — 수학 대응은 #35 소관.
- **형식 힌트의 선례**: `ox: boolean`이 이미 "객관식을 OX 2지선다로" 프롬프트 지시를 주입한다(L649–653) — 시험별 형식 지시를 넣을 자리와 패턴이 이미 있다는 뜻.
- **주관식**: 단답(`answerText` → 자동채점) / 서술형(자기채점) 두 흐름 존재. 배점·부분점수·채점기준표 개념은 없다.

### 2-2. 내신

출처: [경기도교육청 고등학교 학업성적관리 시행지침](https://www.goe.go.kr/resource/old/BBSMSTR_000000030136/BBS_202502171157109041.pdf), [부산광역시교육청 2025학년도 고등학교 학업성적관리 시행지침](https://www.pen.go.kr/upload/dep07/na/bbs_2629/ntt_1135088/doc_7dffv2528=70v5a=48v66=9bve1=7b4cvbbccv4630_v2428.pdf)

- 학교 자율이지만 시도교육청 지침이 공통 골격을 강제한다: 국·수·영·한국사·사회·과학 교과는 선택형 일변도를 지양하고 **서·논술형을 만점의 30% 이상 반영**(시행지침 의무 조항), 서답형에는 **채점기준표(모범답안·유사답안 처리·부분점수) 작성 의무**, 논술형만으로 지필평가 구성도 허용.
- 선택형은 수능 준거의 5지선다 관행. 단, **"모두 고른 것은?" 복수정답형**이 흔하다 — 현행 파이프라인의 '정답 정확히 1개' 검증과 충돌(§4-4).
- 문항 형식 스펙트럼: 선택형(5지) / 서답형-단답형 / 서답형-서술형(조건 제시형: "~를 포함하여 2문장으로 서술하시오") / 논술형.
- 분류는 교육과정 단원 + 성취기준 기반 — **수능과 SubjectDetail 값을 공유할 수 있는 유일한 시험**(같은 교육과정이므로).

### 2-3. 공무원 9급

출처: [9급 국어·영어 2025년부터 현장 직무형 개편(정책브리핑/인사혁신처)](https://m.korea.kr/news/policyNewsView.do?newsId=148922844), [2027년 9급 과목당 20→25문항 개편(경향신문, 행안부·인사혁신처 발표)](https://www.khan.co.kr/article/202507021344001)

- 형식: **4지선다**, 과목당 20문항·20분(**2027년부터 25문항**, 한국사는 한능검 3급 이상으로 대체 → 필기 4과목 체제). 주관식 없음.
- **2025 출제 기조 전환**(인사혁신처): 지식 암기 → 직무 능력 중심. 국어는 이해·추론·비판 사고력 검증(독해·논리 중심, 문법 단순 암기 지양), 영어는 실제 업무 소재(**이메일·안내문** 등 실용문). 신유형은 민간 직무적성검사·**NCS 직업기초능력평가**·수능 등을 분석해 설계됐다고 명시 — 즉 9급 국어/영어의 출제유형은 NCS·수능 유형과 상당 부분 수렴한다.
- 대표 형식: 단독 발문형, 짧은 지문 제시형(1지문 1~2문항), 박스(ㄱㄴㄷ) 합답형, 사료 제시형(한국사), 판례·조문·사례형(행정법).

### 2-4. NCS 직업기초 (#24에서 완료 — 요약만)

- 분류: 10개 능력(구표준 직업기초능력) × **34개 하위요소**가 SubjectDetail level-4. 전체 목록은 `research/ncs-sub-competencies` 브랜치의 `docs/superpowers/research/2026-08-03-ncs-sub-competencies.md`(#30).
- 출제유형 Tag: **모듈형/PSAT형/피듈형**(#32). 이 값은 NCS 전용 — 다른 시험은 같은 카테고리에 자기 값을 채운다(이 문서 §3).
- 형식: 객관식 단일정답, 기관·대행사별 **4지 또는 5지선다 혼재**. PSAT형은 자료해석(표·그래프) 비중이 크고, 모듈형은 표준 교재 지식 기반 단독 발문형.

### 2-5. 토익 RC

출처: [ETS — About the TOEIC Listening and Reading Test](https://www.ets.org/toeic/about/listening-reading.html), [IIBC — Test Format and Content](https://www.iibc-global.org/english/toeic/test/lr/about/format.html)

| 파트 | 문항수 | 형식 |
|---|---|---|
| Part 5 문장 빈칸 | 30 | 단문 1문장 빈칸, 4지선다 (어법/어휘) |
| Part 6 지문 빈칸 | 16 | 지문 4개 × 4문항 세트, 4지선다 (빈칸 3 + **문장삽입 1** 관행) |
| Part 7 독해 | 54 | 단일 지문 10세트(세트당 2~4문항) + **이중지문 2세트·삼중지문 3세트(세트당 5문항)**, 4지선다 |

- RC 100문항 75분, 전부 4지선다 단일정답, 주관식 없음. **지문·발문·선지 전부 영어.**
- LC(Part 1~4)는 오디오 기반 — 범위 밖.
- 핵심 충돌 2가지: 전체 영어(§4-2)와 Part 7 다중지문 세트(§4-3). Part 6도 "지문 1개 + 빈칸 4개가 지문 안에 위치"라는, 발문이 지문에 내장되는 특수 형식이다.

## 3. 시험별로 채울 분류 값 (SubjectDetail level-4 + '출제유형' Tag)

구조는 #24 확정안 그대로. 아래는 각 시험이 그 구조에 넣을 **값의 후보 목록**이다(최종 확정·시딩은 구현 티켓 소관). #31 결정(단계적 미룸 없이 한 번에 채움) 원칙을 따르는 걸 전제로 한다.

### 수능 / 내신 (level-4는 두 시험이 교육과정 단원을 공유)

| 소분류 | SubjectDetail level-4 후보 |
|---|---|
| 국어/문학 | 현대시, 고전시가, 현대소설, 고전소설, 극·수필, 갈래 복합 |
| 국어/독서 | 인문·예술, 사회·문화, 과학·기술, 독서론, 주제통합(가나) |
| 국어/화법과작문 | 화법, 작문, 화법·작문 융합 |
| 국어/언어와매체 | 음운, 단어(형태론), 문장(통사론), 국어사·규범, 매체 |
| 수학/* | 교육과정 단원 그대로 (예: 수학I → 지수함수와 로그함수, 삼각함수, 수열) — #35와 함께 |
